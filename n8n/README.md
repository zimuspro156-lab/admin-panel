# Воркфлоу n8n

Два воркфлоу. Импорт: в n8n → Workflows → Import from File.

| Файл                       | Что делает                                                        | Триггер           |
| -------------------------- | ----------------------------------------------------------------- | ----------------- |
| `01-reviews-to-panel.json` | тянет отзывы с WB и Ozon, просит у OpenAI черновик, шлёт в панель | раз в час, :07    |
| `02-answers-to-mp.json`    | забирает очередь из панели и отправляет ответы на маркетплейсы    | каждые 5 мин + вебхук |

## Что заменить после импорта

1. **Адрес панели.** В обоих файлах найдите `https://ПАНЕЛЬ.example.com` и
   подставьте свой домен. Узлы: «Панель: приём WB», «Панель: приём Ozon»,
   «Панель: взять очередь», «Панель: колбэк».
2. **Credentials.** Плейсхолдеры `REPLACE_*_CREDENTIAL_ID` n8n подсветит
   красным - выберите созданные записи (список в [../docs/setup.md](../docs/setup.md)).
3. **Модель OpenAI.** В узлах «WB: черновик ИИ» и «Ozon: черновик ИИ» поле
   `model` (по умолчанию `gpt-6-luna`). Сверьтесь с текущим списком:
   https://developers.openai.com/api/docs/models
4. **Промпт.** Узел «Промпт для ответов» - единственное место, где задан тон.
   Допишите туда название бренда, стоп-слова и что писать на 1-2 звезды.

После этого включите оба воркфлоу тумблером Active.

## Как устроен первый воркфлоу

Ветки WB и Ozon независимы: падение одной площадки не мешает другой. Пустой
прогон всё равно доходит до панели - так на главном экране видно время
последней синхронизации, а не тишина.

Ошибка API маркетплейса не останавливает выполнение (`onError:
continueRegularOutput`), она превращается в `syncError` и видна в панели.
Сбой генерации черновика тоже не теряет отзыв: он приедет с `aiDraft: null`, и
оператор ответит вручную.

## Как устроен второй воркфлоу

Очередь обрабатывается строго по одному отзыву (`Loop Over Items`, размер
партии 1) - так ответ маркетплейса однозначно сопоставляется со своим отзывом.
Панель при выдаче сразу помечает отзывы как `sending`, поэтому одновременный
запуск по расписанию и по вебхуку не отправит ответ дважды.

Исходы всех отправок собираются в одну партию и уходят в `/api/outbox/callback`.
Если колбэк не дойдёт, отзывы останутся в статусе «Отправляется» - на карточке
есть кнопка «Вернуть в очередь».

## Лимиты

Запросы к OpenAI батчатся по 5 с паузой 1 секунда (`options.batching` в узлах
черновиков). Если упираетесь в rate limit, уменьшите размер батча или увеличьте
интервал.
