# Админ-панель отзывов Wildberries и Ozon

Панель, в которой оператор видит отзывы с обоих маркетплейсов, получает готовый
черновик ответа от ИИ и отправляет его одним нажатием. Вся работа с API
маркетплейсов и генерация черновиков живут в n8n, панель отвечает за хранение,
очередь, правила автоответа и доступы.

## Как это устроено

```
                    ┌──────────────────────── n8n ────────────────────────┐
  раз в час  ──────>│ WB   GET  /api/v1/feedbacks                         │
                    │ Ozon POST /v1/review/list                           │
                    │        │                                            │
                    │        └──> OpenAI: черновик ответа                 │
                    └──────────────────────┬──────────────────────────────┘
                                           │ POST /api/ingest/reviews
                                           v
                              ┌─────────────────────────┐
                              │   Панель (Next.js)      │
                              │   Postgres              │
                              │   правила автоответа    │
                              └───────────┬─────────────┘
                                          │ POST /api/outbox  (n8n забирает очередь)
                                          v
                    ┌──────────────────────────────────────────────────────┐
                    │ WB   POST /api/v1/feedbacks/answer                   │
                    │ Ozon POST /v1/review/comment/create                  │
                    │        └──> POST /api/outbox/callback (исход)        │
                    └──────────────────────────────────────────────────────┘
```

Токены WB, Ozon и ключ OpenAI хранятся только в credentials n8n. Панель никогда
не обращается к маркетплейсам напрямую, поэтому её можно держать в облаке, не
вынося туда секреты продавца.

## Что умеет

- Лента отзывов WB и Ozon с фильтрами: только WB, только Ozon или всё вместе,
  плюс статус, оценка и поиск по тексту, товару и SKU.
- Черновик ИИ показан над полем ввода. «Заполнить» переносит его в поле для
  правки, «Поставить» отправляет как есть.
- Автоответ без аппрува по правилам: список оценок, площадки, задержка (окно,
  когда оператор ещё может снять ответ) и лимит отправок в час.
- Пользователи с логином и паролем, две роли: администратор и оператор.
  Оператор работает только с отзывами, настройки и пользователи ему закрыты.
- Журнал синхронизаций и аудит действий.

## Статусы отзыва

| Статус        | Что значит                                                   |
| ------------- | ------------------------------------------------------------ |
| `new`         | пришёл из n8n, ждёт оператора                                |
| `queued`      | ответ подтверждён вручную или правилом автоответа            |
| `sending`     | забран воркфлоу отправки, маркетплейс ещё не подтвердил      |
| `sent`        | маркетплейс принял ответ                                     |
| `failed`      | отправка сорвалась, видно текст ошибки, можно повторить      |
| `skipped`     | оператор решил не отвечать                                   |

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 ·
Drizzle ORM + Postgres · jose (сессия в HttpOnly-куке) · bcryptjs · zod

## Быстрый старт локально

```bash
npm install
cp .env.example .env.local     # заполните DATABASE_URL, SESSION_SECRET, N8N_API_KEY
npm run db:migrate
npm run dev
```

Откройте http://localhost:3000 - пока в базе нет пользователей, панель предложит
создать администратора. Дальше он заводит остальных на странице «Пользователи».

Генерация секретов:

```bash
openssl rand -base64 48   # SESSION_SECRET
openssl rand -hex 32      # N8N_API_KEY
```

## Переменные окружения

| Переменная          | Обязательна | Назначение                                              |
| ------------------- | ----------- | ------------------------------------------------------- |
| `DATABASE_URL`      | да          | строка подключения к Postgres                           |
| `SESSION_SECRET`    | да          | подпись куки сессии, минимум 32 символа                 |
| `N8N_API_KEY`       | да          | общий ключ машинных ручек, он же в credentials n8n      |
| `DATABASE_POOL_MAX` | нет         | размер пула, по умолчанию 5                             |
