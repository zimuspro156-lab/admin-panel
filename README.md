# Админ-панель отзывов Wildberries и Ozon

Панель, в которой оператор видит отзывы с обоих маркетплейсов, получает готовый
черновик ответа от ИИ и отправляет его одним нажатием. Токены вводятся в самой
панели, n8n работает планировщиком.

## Как это устроено

```
   n8n (планировщик)
      раз в час   ──POST /api/jobs/sync───┐
      раз в 10 мин ─POST /api/jobs/flush──┤
                                          v
                        ┌─────────────────────────────────┐
                        │  Панель (Next.js + Postgres)    │
                        │                                 │
                        │  токены WB / Ozon / OpenAI      │
                        │  зашифрованы в базе             │
                        │  правило автоответа             │
                        └───────┬─────────────────────────┘
                                │
              ┌─────────────────┼──────────────────┐
              v                 v                  v
   WB Feedbacks API     Ozon Seller API      OpenAI API
   GET  /feedbacks      POST /review/list    черновики
   POST /feedbacks/     POST /review/
        answer               comment/create
```

Панель сама ходит во все внешние API, поэтому секреты не размазаны по двум
системам. n8n знает только адрес панели и один ключ `N8N_API_KEY`, которым
запускает задания. На общем инстансе n8n появляется всего два узла-планировщика,
так что соседние воркфлоу не задеты.

## Что умеет

- Лента отзывов WB и Ozon с фильтрами: только WB, только Ozon или всё вместе,
  плюс статус, оценка и поиск по тексту, товару и SKU.
- Черновик ИИ показан над полем ввода. «Заполнить» переносит его в поле для
  правки, «Поставить» отправляет как есть - ответ уходит сразу, а не по крону.
- Автоответ - один переключатель. Включён: черновики уходят на маркетплейс
  сами. Выключен: всё ждёт оператора. Отзыв без черновика остаётся оператору в
  любом случае.
- Раздел «Подключения»: токен WB, Client-Id и Api-Key Ozon, ключ OpenAI.
  Хранятся зашифрованными (AES-256-GCM), есть кнопка живой проверки доступов.
- Тон ответов ИИ правится в настройках, без переустановки.
- Пользователи с логином и паролем, роли администратор и оператор. Оператору
  доступны только отзывы.
- Журнал синхронизаций на главном экране и аудит действий.

## Статусы отзыва

| Статус    | Что значит                                              |
| --------- | ------------------------------------------------------- |
| `new`     | пришёл из выгрузки, ждёт оператора                      |
| `queued`  | ответ подтверждён вручную или автоответом               |
| `sending` | отправляется прямо сейчас                               |
| `sent`    | маркетплейс принял ответ                                |
| `failed`  | отправка сорвалась, виден текст ошибки, можно повторить |
| `skipped` | оператор решил не отвечать                              |

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 ·
Drizzle ORM + Postgres · jose (сессия в HttpOnly-куке) · bcryptjs · zod

## Развёртывание на сервере

```bash
git clone <репозиторий> && cd admin-panel/deploy
bash install.sh
```

Скрипт ставит Docker, генерирует секреты, поднимает Postgres, накатывает
миграции и запускает панель за Caddy. Подробности и настройка домена:
[docs/setup.md](docs/setup.md).

## Локальный запуск

```bash
npm install
cp .env.example .env.local     # заполнить DATABASE_URL, SESSION_SECRET, ENCRYPTION_KEY, N8N_API_KEY
npm run db:migrate
npm run dev
```

При первом открытии панель предложит создать администратора.

Генерация секретов:

```bash
openssl rand -base64 48   # SESSION_SECRET
openssl rand -base64 32   # ENCRYPTION_KEY (ровно 32 байта)
openssl rand -hex 32      # N8N_API_KEY
```

## Переменные окружения

| Переменная          | Обязательна | Назначение                                                  |
| ------------------- | ----------- | ----------------------------------------------------------- |
| `DATABASE_URL`      | да          | строка подключения к Postgres                               |
| `SESSION_SECRET`    | да          | подпись куки сессии, минимум 32 символа                     |
| `ENCRYPTION_KEY`    | да          | шифрование токенов в базе, ровно 32 байта в base64          |
| `N8N_API_KEY`       | да          | ключ для `/api/jobs/*`, он же в credentials n8n             |
| `DATABASE_POOL_MAX` | нет         | размер пула, по умолчанию 5                                 |
| `WB_API_BASE`       | нет         | подмена адреса API, нужна только для отладки против мока    |
| `OZON_API_BASE`     | нет         | то же для Ozon                                              |
| `OPENAI_API_BASE`   | нет         | то же для OpenAI                                            |

Если `ENCRYPTION_KEY` потерян, токены расшифровать нельзя: панель это переживёт,
но доступы в разделе «Подключения» придётся ввести заново.
