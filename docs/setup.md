# Развёртывание

Схема: панель в облаке, n8n отдельно. Секреты маркетплейсов остаются в n8n.

## 1. База данных

Подойдёт любой managed Postgres: Neon, Supabase, Yandex Cloud, Selectel.

Для serverless-панели берите **pooler-строку**, а не прямое подключение: у
Supabase это порт 6543, у Neon хост с суффиксом `-pooler`. Прямое подключение
из serverless быстро упирается в лимит соединений.

Накатить схему:

```bash
DATABASE_URL='postgresql://...' npm run db:migrate
```

## 2. Панель

Разворачивается как обычное Next.js приложение (Vercel, Netlify, Cloud.ru,
собственный сервер с `npm run build && npm start`).

Переменные окружения:

```
DATABASE_URL=postgresql://...
SESSION_SECRET=<openssl rand -base64 48>
N8N_API_KEY=<openssl rand -hex 32>
```

После первого деплоя откройте корень сайта: пока в базе нет пользователей,
панель покажет форму создания администратора. Как только он создан, страница
`/setup` закрывается сама.

Проверка живости: `GET /api/health`.

## 3. Токен Wildberries

Кабинет продавца → Профиль → Настройки → Доступ к API → создать токен.

- категория: **Вопросы и отзывы**;
- флаг **«Только чтение» снять** - иначе отправка ответов вернёт ошибку.

Методы, на которых работает интеграция (host `https://feedbacks-api.wildberries.ru`):

| Метод                             | Назначение                 |
| --------------------------------- | -------------------------- |
| `GET /api/v1/feedbacks`           | список отзывов             |
| `POST /api/v1/feedbacks/answer`   | ответить на отзыв          |
| `PATCH /api/v1/feedbacks/answer`  | отредактировать ответ      |

Справочник: https://dev.wildberries.ru/docs/openapi/user-communication

## 4. Ключи Ozon

Seller → Настройки → API ключи: понадобятся `Client-Id` и `Api-Key`.

**Важно:** методы `/v1/review/*` доступны только с подпиской
**«Управление отзывами» (Premium Plus)**. Она запущена 1 апреля 2026: первый
месяц 0,8% от цены проданного товара, со второго - 1,3%, со скидкой 50% при
Premium Pro. Без подписки Ozon отдаёт ошибку, и в панели это будет видно в
журнале синхронизаций. Wildberries при этом продолжит работать: ветки в
воркфлоу независимы.

| Метод                             | Назначение                    |
| --------------------------------- | ----------------------------- |
| `POST /v1/review/list`            | список отзывов                |
| `POST /v1/review/info`            | отзыв по id                   |
| `POST /v1/review/comment/create`  | комментарий (ответ) к отзыву  |

Справочник: https://docs.ozon.ru/api/seller/

## 5. n8n

Нужен свой инстанс (self-hosted Docker или n8n Cloud). Панели он должен быть
доступен по HTTPS, если вы используете немедленную отправку по вебхуку.

### Credentials

Создайте четыре записи:

| Название             | Тип                             | Содержимое                                                        |
| -------------------- | ------------------------------- | ----------------------------------------------------------------- |
| `WB Feedbacks token` | Header Auth                     | Name: `Authorization`, Value: токен WB                            |
| `Ozon Seller API`    | Custom Auth                     | `{"headers":{"Client-Id":"...","Api-Key":"..."}}`                 |
| `OpenAI Bearer`      | Header Auth                     | Name: `Authorization`, Value: `Bearer sk-...`                     |
| `Панель x-api-key`   | Header Auth                     | Name: `x-api-key`, Value: `N8N_API_KEY` панели                    |

### Импорт воркфлоу

См. [../n8n/README.md](../n8n/README.md).

## 6. Немедленная отправка (необязательно)

Без неё ответы уходят по расписанию - до 5 минут ожидания. С ней нажатие
«Поставить» сразу дёргает n8n.

1. В воркфлоу «Панель → МП: отправка ответов» откройте узел «Вебхук от панели»
   и скопируйте **Production URL**.
2. Вставьте его в панели: Настройки → «Вебхук n8n для немедленной отправки».

Если вебхук недоступен, ничего не ломается: отзыв остаётся в очереди и его
подберёт расписание. Панель логирует неудачный вызов и не блокирует оператора.

## 7. Настройка автоответа

Настройки → «Автоответ без аппрува». Разумный старт:

- оценки **5 и 4**, оценки 1-3 оставить на ручной ответ;
- задержка **15-30 минут** - окно, чтобы снять ответ с очереди;
- лимит **20-30 в час**.

Автоответ никогда не срабатывает без черновика ИИ: если генерация упала, отзыв
останется оператору.

## Эксплуатация

- **Отзывы не приходят.** Главный экран панели показывает время последнего
  прогона по каждой площадке и текст ошибки. Дальше - история выполнений в n8n.
- **Отзыв завис в «Отправляется».** Значит n8n не прислал колбэк. На карточке
  есть «Вернуть в очередь».
- **Смена тона ответов.** Узел «Промпт для ответов» в первом воркфлоу. Деплой
  панели не нужен.
- **Смена модели.** Поле `model` в узлах «черновик ИИ». Актуальный список id:
  https://developers.openai.com/api/docs/models
