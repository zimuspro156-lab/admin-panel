# Развёртывание

## 1. Сервер

Нужен Linux с root-доступом, 2 vCPU и 2 ГБ памяти хватит.

```bash
git clone <репозиторий> admin-panel
cd admin-panel/deploy
bash install.sh
```

Скрипт поставит Docker, сгенерирует секреты в `deploy/.env`, поднимет Postgres,
накатит миграции и запустит панель за Caddy. В конце он напечатает
`N8N_API_KEY` - он понадобится для n8n.

Первый запуск идёт по HTTP на IP сервера. Когда появится домен, пропишите его
в `deploy/.env` и перезапустите Caddy:

```bash
sed -i 's|^PANEL_DOMAIN=.*|PANEL_DOMAIN=panel.example.com|' .env
docker compose up -d caddy
```

Caddy сам выпустит сертификат Let's Encrypt. Пока панель работает по HTTP,
кука сессии ходит незашифрованной - это временное состояние, домен стоит
сделать до того, как панелью начнут пользоваться сотрудники.

Обновление до новой версии:

```bash
git pull
cd deploy
docker compose build panel
docker compose run --rm --entrypoint sh panel -c 'npx --yes drizzle-kit migrate'
docker compose up -d panel
```

Резервная копия базы:

```bash
docker compose exec db pg_dump -U reviews reviews | gzip > backup-$(date +%F).sql.gz
```

Дамп базы бесполезен без `ENCRYPTION_KEY` из `deploy/.env`: токены в нём
зашифрованы. Храните копию ключа отдельно.

## 2. Первый вход

Откройте панель: пока в базе нет пользователей, она покажет форму создания
администратора. Как только он создан, страница `/setup` закрывается сама.
Остальных сотрудников администратор заводит в разделе «Пользователи».

## 3. Токен Wildberries

Кабинет продавца → Профиль → Настройки → Доступ к API → создать токен.

- категория: **Вопросы и отзывы**;
- флаг **«Только чтение» снять**. С ним выгрузка отзывов работает, а отправка
  ответов возвращает 403 - панель в этом случае прямо пишет про флаг в тексте
  ошибки на карточке отзыва.

Вставьте токен в разделе «Подключения» и нажмите «Проверить».

Методы, которые использует панель (host `https://feedbacks-api.wildberries.ru`):

| Метод                                  | Назначение             |
| -------------------------------------- | ---------------------- |
| `GET /api/v1/feedbacks`                | список отзывов         |
| `GET /api/v1/feedbacks/count-unanswered` | проверка доступа     |
| `POST /api/v1/feedbacks/answer`        | ответить на отзыв      |

Справочник: https://dev.wildberries.ru/docs/openapi/user-communication

## 4. Ключи Ozon

Seller → Настройки → API ключи: `Client-Id` и `Api-Key`. Вставьте их в
«Подключения».

**Важно:** методы `/v1/review/*` доступны только с подпиской **«Управление
отзывами» (Premium Plus)**. Она запущена 1 апреля 2026: первый месяц 0,8% от
цены проданного товара, со второго 1,3%, со скидкой 50% при Premium Pro. Без
подписки Ozon отвечает 403, и панель покажет это в журнале синхронизаций.
Wildberries при этом продолжит работать: площадки обрабатываются независимо.

| Метод                            | Назначение                   |
| -------------------------------- | ---------------------------- |
| `POST /v1/review/list`           | список отзывов               |
| `POST /v1/review/count`          | проверка доступа и подписки  |
| `POST /v1/review/comment/create` | ответ на отзыв               |

Справочник: https://docs.ozon.ru/api/seller/

## 5. Ключ OpenAI

Вставьте в «Подключения». Модель задаётся в «Настройках», по умолчанию
`gpt-6-luna`. Актуальный список идентификаторов:
https://developers.openai.com/api/docs/models

Без ключа отзывы всё равно будут приходить, но черновиков не будет и отвечать
придётся вручную.

## 6. n8n

Панель не требует n8n для ручной работы: оператор может отвечать сразу, а
выгрузку запускать кнопкой «Выгрузить отзывы сейчас» в настройках. n8n нужен,
чтобы это происходило по расписанию.

1. Создайте одну credential: **Header Auth**, Name `x-api-key`, Value -
   `N8N_API_KEY`, который напечатал `install.sh`.
2. Импортируйте [../n8n/01-sync-reviews.json](../n8n/01-sync-reviews.json) и
   [../n8n/02-flush-answers.json](../n8n/02-flush-answers.json).
3. В обоих замените `https://ПАНЕЛЬ.example.com` на адрес панели и выберите
   созданную credential.
4. Включите оба тумблером Active.

Это два узла в каждом воркфлоу, на соседние воркфлоу инстанса они не влияют.

## 7. Автоответ

Настройки → «Автоответ». Один переключатель: включён - черновики ИИ уходят на
маркетплейс сами, выключен - каждый ответ отправляет оператор.

Перед включением стоит неделю поработать вручную и вычитать черновики: при
включённом автоответе под автоматический ответ попадают и отзывы на одну
звезду. Если такие лучше оставить человеку, скажите об этом в промпте и держите
автоответ выключенным до тех пор, пока качество не устроит.

Технический предохранитель: не больше 60 автоответов в час. Ручные ответы им
не ограничены.

## Эксплуатация

- **Отзывы не приходят.** Главный экран показывает время последнего прогона по
  каждой площадке и текст ошибки. Дальше - история выполнений в n8n.
- **Отзыв завис в «Отправляется».** На карточке есть «Вернуть в очередь».
- **Ошибка на карточке.** Текст приходит от маркетплейса как есть, включая
  подсказку про флаг «Только чтение» и про подписку Ozon.
- **Смена тона ответов.** Настройки → «Как ИИ должен отвечать».
- **Проверка доступов.** Подключения → «Проверить»: по одному настоящему
  запросу в каждый сервис.
