# Задания, которые запускает n8n

Две ручки. Обе требуют заголовок `x-api-key` со значением `N8N_API_KEY`;
сравнение постоянное по времени. Ответ всегда JSON, включая ошибки: пустой 500
без тела не возвращается, чтобы причина была видна в логе выполнения n8n.

| Код | Когда                                            |
| --- | ------------------------------------------------ |
| 200 | задание выполнено, детали в теле (`ok` может быть false) |
| 401 | нет или неверный `x-api-key`                     |
| 422 | тело не прошло валидацию                         |
| 500 | необработанный сбой панели, текст в `error`      |

Обе ручки безопасно вызывать параллельно: очередь разбирается через
`FOR UPDATE SKIP LOCKED`, поэтому один отзыв не будет отправлен дважды.

## POST /api/jobs/sync

Полный прогон выгрузки: забирает неотвеченные отзывы с WB и Ozon токенами из
раздела «Подключения», сохраняет новые, генерирует черновики через OpenAI и,
если автоответ включён, ставит их в очередь на отправку.

Тело: `{}`.

```jsonc
{
  "ok": true,
  "results": [
    {
      "marketplace": "wb",
      "ok": true,
      "fetched": 12,      // сколько отдал маркетплейс
      "created": 3,       // сколько отзывов новые
      "updated": 9,       // у скольких обновился текст
      "drafted": 3,       // для скольких сгенерирован черновик
      "queued": 3,        // сколько ушло в автоответ
      "error": null
    },
    { "marketplace": "ozon", "ok": false, "error": "Ozon: HTTP 403 ... (методы отзывов требуют подписки «Управление отзывами» / Premium Plus)" }
  ]
}
```

Площадки независимы: недоступный Ozon не мешает выгрузке WB. `ok: false` на
верхнем уровне означает, что хотя бы одна площадка отработала с ошибкой,
но HTTP-код при этом остаётся 200 - иначе n8n покажет только «красный узел»
без подробностей.

Уже отвеченный или подтверждённый отзыв повторная выгрузка не откатывает:
обновляется только текст отзыва. Черновик генерируется один раз, на повторных
прогонах OpenAI не дёргается.

За один прогон генерируется не больше 50 черновиков - предохранитель от
неожиданного счёта, если разом приедет большая выгрузка.

## POST /api/jobs/flush

Досылает накопившуюся очередь ответов. Нужен как страховка: ответ оператора
уходит сразу при нажатии «Поставить», а сюда попадают автоответы и то, что
не ушло с первой попытки.

```jsonc
{ "limit": 25, "reviewId": 42 }   // оба поля необязательны
```

```jsonc
{ "ok": true, "attempted": 3, "sent": 3, "failed": 0, "errors": [] }
```

Автоотправка ограничена 60 ответами в час - технический предохранитель, чтобы
не упереться в лимиты маркетплейса. Ручные ответы оператора он не затрагивает.

## GET /api/health

Без авторизации. `{ "ok": true, "db": "up" }` или 503, если база недоступна.
Годится для healthcheck.
