# Контракты машинных ручек

Эти три ручки зовёт n8n. Все требуют заголовок `x-api-key` со значением
`N8N_API_KEY`; сравнение ключа постоянное по времени. Ответ всегда JSON, включая
ошибки: пустой 500 без тела не возвращается, чтобы причина была видна в логе
воркфлоу.

| Код | Когда                                       |
| --- | ------------------------------------------- |
| 200 | обработано                                  |
| 401 | нет или неверный `x-api-key`                |
| 422 | тело не прошло валидацию, в `issues` детали |
| 500 | сбой на стороне панели, текст в `error`     |

## POST /api/ingest/reviews

Приём выгрузки. Идемпотентен по паре (`marketplace`, `externalId`): повторный
прогон обновляет текст отзыва, но не откатывает статус уже подтверждённого или
отправленного ответа. Черновик ИИ перезаписывается только пока отзыв в статусе
`new`.

```jsonc
{
  "marketplace": "wb",          // wb | ozon
  "syncError": null,            // текст ошибки прогона, попадёт в журнал синхронизаций
  "reviews": [
    {
      "externalId": "HhIuBJwBaQjBJ3NNQrLp",  // обязателен
      "rating": 4,                            // 1..5 или null
      "text": "Чайник хороший, но шнур короткий",
      "pros": "Быстро кипятит",               // у Ozon всегда null
      "cons": "Короткий шнур",
      "authorName": "Мария",
      "productName": "Чайник электрический 1.7 л",
      "productSku": "123456789",              // nmId у WB, sku у Ozon, строкой
      "productBrand": "Home",
      "productArticle": "KT-17",
      "photos": ["https://feedback.wbbasket.ru/f.jpg"],
      "mpCreatedAt": "2026-09-30T06:11:22Z",
      "aiDraft": "Мария, спасибо за отзыв...",
      "aiModel": "gpt-6-luna",
      "raw": {}                               // исходный объект маркетплейса
    }
  ]
}
```

Ответ: `{ "ok": true, "received": 1, "created": 1, "updated": 0, "queued": 0 }`,
где `queued` - сколько отзывов сразу ушло в автоответ по правилам из настроек.

Пустой прогон (`"reviews": []`) тоже стоит отправлять: он обновляет время
последней синхронизации на главном экране.

## POST /api/outbox

Забирает готовые к отправке ответы и переводит их в статус `sending`. Выборка
идёт через `FOR UPDATE SKIP LOCKED`, поэтому два параллельных прогона n8n не
получат один и тот же отзыв и ответ не уйдёт дважды.

```jsonc
{ "limit": 25, "reviewId": 42 }   // оба поля необязательны
```

`reviewId` используется сценарием немедленной отправки: панель дёргает вебхук
n8n сразу после нажатия «Поставить» и передаёт конкретный отзыв.

```jsonc
{
  "ok": true,
  "count": 1,
  "autoBudget": 29,          // сколько автоответов ещё можно отправить в этот час
  "items": [
    {
      "id": 42,                   // внутренний id, вернуть его в колбэке
      "marketplace": "wb",
      "externalId": "HhIuBJwBaQjBJ3NNQrLp",
      "answerText": "Мария, спасибо за отзыв...",
      "answerSource": "manual",   // manual | auto
      "attempts": 1,
      "ozonMarkProcessed": true   // передавать ли mark_review_as_processed
    }
  ]
}
```

Ручные ответы не ограничены лимитом: оператор их уже подтвердил. Лимит
`autoReplyMaxPerHour` считается только по автоответам, отправленным за последний
час. Отзыв с непрошедшей задержкой (`send_after` в будущем) не выдаётся.

## POST /api/outbox/callback

Исход отправки по каждому отзыву из партии. Без колбэка отзывы навсегда
останутся в статусе `sending`.

```jsonc
{
  "results": [
    { "id": 42, "ok": true, "externalCommentId": "c-1" },
    { "id": 43, "ok": false, "error": "WB: отзыв уже обработан" }
  ]
}
```

Ответ: `{ "ok": true, "sent": 1, "failed": 1 }`.

## GET /api/health

Без авторизации. `{ "ok": true, "db": "up" }` или 503, если база недоступна.
Годится для healthcheck хостинга.
